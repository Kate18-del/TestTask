# Управление информатизации — Сочинский государственный университет

## 1. Описание концепции страницы


Мне хотелось сделать страницу, которая не выглядит как сухой технический справочник, но при этом не теряет серьёзности. Ведь управление информатизации — это ребята, которые обеспечивают работу всего университета, и страница должна это отражать: строгость и порядок в структуре, но открытость и дружелюбие в подаче. Поэтому я взяла фирменный синий СОЧИ ГУ как базу — он даёт ощущение надёжности, а мягкие скругления карточек, круглая обрезка фото сотрудников и плавные hover-эффекты добавляют человечности и современности.

Визуально всё строится на чёткой иерархии: крупный заголовок на первом экране задаёт направление, карточки трёх отделов помогают быстро понять структуру, а блок с сотрудниками и контактами делает страницу живой и доступной. На мобилке сетка просто и аккуратно перестраивается в вертикальный список, чтобы сохранить удобство на любом экране. Главное, чтобы человек, зайдя сюда, сразу понял, куда попал, и не потерялся в информации.

### Основные разделы:

| Раздел | Описание |
|--------|----------|
| **Шапка сайта (header)** | Логотип университета, основная навигация с быстрыми ссылками на ключевые разделы, кнопка поиска и мобильное меню. |
| **Герой-блок (hero)** | Крупный заголовок «УПРАВЛЕНИЕ ИНФОРМАТИЗАЦИИ» с описанием и кнопкой перехода к основному контенту. Фоновое изображение создаёт технологичную атмосферу. |
| **Об управлении** | Четыре карточки, описывающих ключевые направления работы управления: информационные системы, техническая поддержка, телекоммуникации и защита информации. |
| **Организационная структура** | Визуализация структуры управления с помощью древовидной схемы. Карточки трёх отделов с номерами, описаниями и интерактивными кнопками. |
| **Сотрудники** | Карточки ключевых сотрудников с фото, должностью, телефоном и email. Кнопка «Все сотрудники» открывает модальное окно. |
| **Контакты** | Информация о приёмной комиссии, главном корпусе и общем отделе с адресами, телефонами и графиком работы. |
| **Подвал (footer)** | Копирайт, быстрые ссылки на разделы, информация об образовательной организации и политика обработки данных. |

### Дизайн-система:

- **Цветовая палитра:** Синяя гамма (`#00204F`, `#002F6C`, `#1676E8`, `#2C82EF`) — соответствует фирменному стилю университета.
- **Типографика:** Шрифт Inter (запасной Arial), обеспечивающий хорошую читаемость.
- **Адаптивность:** Полноценная поддержка мобильных устройств (планшеты, смартфоны) с перестройкой сетки и скрытием элементов.

## 2. Инструкция по запуску проекта

### Способ 1: Открыть напрямую в браузере (простой)

1. Распакуйте архив с проектом
2. Откройте файл `index.html` в любом современном браузере:
   - Двойным щелчком мыши
   - Или через меню браузера: `Файл → Открыть файл`

### Способ 2: Локальный сервер (рекомендуемый)

Для корректной работы всех изображений и стилей рекомендуется использовать локальный сервер:

**Вариант A: VS Code + Live Server (самый простой)**
1. Установите расширение **Live Server** в VS Code
2. Нажмите правой кнопкой на `index.html`
3. Выберите **"Open with Live Server"**
4. Страница откроется по адресу `http://127.0.0.1:5500/`

3. Реализованные JavaScript-функции
Функция	Описание	Технология
Фиксация шапки	При скролле шапка становится «прилипшей» (sticky) с тенью	window.addEventListener('scroll')
Мобильное меню	Бургер-меню открывается/закрывается по клику, блокировка скролла при открытом меню	click event, aria-expanded, classList.toggle
Закрытие баннера	Клик на крестик скрывает тестовый баннер	click event, hidden attribute
Анимация появления	Элементы плавно появляются при прокрутке (эффект fade-in)	IntersectionObserver API
Модальное окно	Открытие окна «Все сотрудники» по клику, закрытие по крестику, бэкдропу и клавише ESC	click event, keydown event
Плавный скролл	Все якорные ссылки плавно прокручивают к нужному разделу	scroll-behavior: smooth в CSS
Доступность	Управление с клавиатуры, ARIA-атрибуты, skip-link	ARIA, семантический HTML
