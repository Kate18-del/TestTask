# Задание 2 — Адаптивная вёрстка

## Что реализовано
- Семантическая HTML-разметка: `header`, `main`, `section`, `article`, `footer`, `nav`.
- Адаптивные версии:
  - 320–480 px — мобильные устройства;
  - 768 px — планшеты;
  - 1200+ px — десктоп.
- Дизайн повторяет предоставленную концепцию: тёмно-синяя шапка, технологичный Hero, карточки, организационная структура, сотрудники, контакты и footer.
- Используется `Inter` через системный стек шрифтов (`Inter, Arial, sans-serif`), чтобы проект запускался без внешних библиотек.
- CSS использует общие переменные цветов и повторно используемые классы, без фреймворков.
- JS реализует:
  1. мобильное меню;
  2. закрытие тестового уведомления;
  3. анимацию блоков при прокрутке;
  4. кнопку «Наверх»;
  5. модальное окно «Все сотрудники»;
  6. плавную прокрутку по якорям через CSS.

## Как запустить
1. Распаковать архив.
2. Открыть `index.html` в браузере.
3. Для проверки адаптива открыть DevTools → Toggle device toolbar и проверить ширины 320, 375, 480, 768, 1200 и 1440 px.

Или
1. Откройте папку проекта в VS Code
2. Установите расширение Live Server
3. Нажмите правой кнопкой на index.html → Open with Live Server

Локальный сервер не требуется: проект использует только HTML/CSS/JS.
